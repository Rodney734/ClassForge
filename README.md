# 📖 Overview

ClassForge is an intelligent classroom management platform designed to modernize teaching and learning within higher education institutions. It consolidates multiple academic tools into a single mobile application, eliminating the need for lecturers and students to switch between various communication, attendance, assignment, and collaboration platforms.

Originally conceived to address challenges experienced by colleges and universities in Malawi, ClassForge aims to improve academic communication, increase student engagement, simplify administrative processes, and support digital transformation in resource-constrained educational environments.

Built with **Flutter** and powered by **Firebase**, the platform provides real-time synchronization, secure authentication, cloud storage, and scalable infrastructure while maintaining an intuitive and user-friendly experience.

# ❌ The Problem

Many higher education institutions continue to rely on disconnected digital tools and manual processes for classroom management.

These fragmented systems often result in:

| Challenge | Impact |
|-----------|--------|
| **Fragmented Communication** | Students and lecturers rely on WhatsApp, email, and SMS, leading to information loss |
| **Manual Attendance Tracking** | Time-consuming, prone to fraud, no real-time visibility |
| **Delayed Assignment Handling** | Manual submission, grading, and feedback processes |
| **No Centralized Notifications** | Important announcements often go unnoticed |
| **Limited Engagement Tools** | Lack of interactive features for enhanced learning |
| **No Live Class Support** | No dedicated platform for conducting live virtual lectures |
| **Disconnected Systems** | Students and lecturers switch between multiple apps |
| **Low Digital Adoption** | Resistance to technology due to complexity |

As institutions continue embracing digital learning, there is an increasing need for a unified platform capable of supporting both physical and virtual classrooms.

---

# 💡 Our Solution

ClassForge centralizes classroom management into a single mobile application by integrating essential academic services into one seamless experience.

## 👨‍🎓 Students Can:

- Join their registered classes
- Participate in class discussions
- Receive announcements instantly
- Submit assignments digitally
- Attend live virtual classes
- View attendance history
- Access course materials
- Interact with an AI-powered tutor
- Ask questions in the Q&A forum
- Earn streaks through participation

## 👨‍🏫 Lecturers Can:

- Create and manage classes
- Monitor attendance via GPS
- Share learning materials
- Grade assignments
- Schedule live lectures
- Communicate with students in real time
- Generate attendance reports (PDF)
- Monitor student engagement
- Post announcements and notices
- Create and manage assignments
